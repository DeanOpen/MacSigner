# Biểu tượng ứng dụng ký số

- `esigner.png`: biểu tượng gốc từ `icon48.ico` của eSigner Java
  (`C:\Program Files (x86)\eSigner Java\icon48.ico`), 48 × 48 pixel.
- `ctsigninghub.png`: biểu tượng gốc từ tài nguyên `app.ico` của CTSigningHub
  (`CTSIGN/evidence/decompiled/app.ico`), 32 × 32 pixel.

Chuyển ICO sang PNG, giữ nguyên hình, màu và nền trong suốt.
Logo thuộc chủ sở hữu tương ứng. Các PNG được đóng gói cùng giao diện,
không phụ thuộc thư mục cài ứng dụng trên máy người dùng.
